# 📚 Verbal Ability Trainer

A modern web-based platform designed to help students prepare for the TCS National Qualifier Test (TCS NQT) Verbal Ability section.

The application provides an interactive learning experience with Passage Recall, Sentence Completion, performance analytics, and detailed feedback to improve communication and recall skills.


## 🌐 Live Demo

👉 https://your-vercel-link.vercel.app


## ✨ Features

- 24+ TCS-style passages

- Random & Sequential practice
- Difficulty levels

- Organization

⭐ One recommendation

Avoid naming it **"TCS NQT Verbal Trainer"** in the project title or branding because it can imply an official affiliation.

Instead, use a neutral title like:

- **Verbal Ability Trainer**
- **Placement Verbal Practice**
- **Campus Verbal Prep**
- **Verbal Recall & Practice**

Then describe it as:

> *"Designed for students preparing for placement assessments such as TCS NQT."*

This makes the purpose clear without suggesting that it's an official TCS product.
